# 🦸 AvengersCardGame

Telegram-бот на Java, в котором пользователи раз в день получают карточки мстителей разной редкости. Карточки можно разбирать на «кусочки», крафтить из них новые, продавать и покупать, а также сражаться друг с другом.

**Авторы:** Григорян Нарек, Проскурнин Георгий

---

## 📌 Этапы разработки

### Задача 1. Фундамент: бот, БД и базовые функции

**Цель:** рабочий Telegram-бот с сохранением пользователей.

- Команда `/start` — бот выводит приветственное сообщение, регистрация игрока при первом вызове.
- Команда `/profile` — вывод баланса и количества карточек.

- пример /start:
- user: /start
- bot: привет! это бот AvengersCardGame. тут ты можешь собирать свою коллекцию карточек мстителей, обмениваться карточками с другими игроками и устраивать сражения.

- пример /profile:
- user: /profile
- bot: твой баланс: **количество щитов**. в твоей коллекции **N** карточек

**Результат:** бот отвечает, пользователи сохраняются, есть каркас проекта.
