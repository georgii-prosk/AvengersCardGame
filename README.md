# 🦸 AvengersCardGame

Telegram-бот на Java, в котором пользователи раз в день получают карточки мстителей разной редкости. Карточки можно разбирать на «кусочки», крафтить из них новые, продавать и покупать, а также сражаться друг с другом.

**Авторы:** Григорян Нарек, Проскурнин Георгий

---

## 📌 Этапы разработки

### Задача 1. Фундамент: бот, БД и базовые функции

**Цель:** рабочий Telegram-бот с сохранением пользователей.

- Команда `/start` — бот выводит приветственное сообщение, регистрация игрока при первом вызове.
- Команда `/profile` — вывод имени, описания профиля, баланса и количества карточек.
- Команда `/help` - вывод команд бота и их описание (что делают команды).
- Команда `/setname <name>` - пользователь может изменить отображаемое для других игроков имя в боте. (имя тг аккаунта - имя по умолчанию)
- Команда `/setbio <bio>` - пользователь может добавить короткое описание своего профиля.

- Неизвестная команда - бот выводит сообщение о неизвестной команде и вызывает `/help`

- пример `/start`:
- user: `/start`
- bot: привет! это бот AvengersCardGame. тут ты можешь собирать свою коллекцию карточек мстителей, обмениваться карточками с другими игроками и устраивать сражения.

- пример `/profile`:
- user: `/profile`
- bot: твой баланс: имя: **имя**. описание **описание**, **количество щитов**. в твоей коллекции **N** карточек

- пример `/help`:
- user: `/help`
- bot: `/start` - запуск бота, `/help` - помощь, `/profile` - информация о твоем профиле в боте и т.д.

- пример `/setname <name>`:
- user: `/start <NEWUSERNAME>`
- bot: вы сменили отображаемое имя на **NEWUSERNAME**.

- пример `/setbio <bio>`:
- user: `/setbio <NEWBIO>`
- bot: вы обновили описание своего профиля на **NEWBIO**.

**Результат:** бот отвечает, пользователи сохраняются, есть каркас проекта.
